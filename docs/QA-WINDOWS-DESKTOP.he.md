# רשימת בדיקה ידנית: Windows 10/11 על מחשב שולחני אמיתי

<div dir="rtl">

הבדיקות כאן הן אלה שאי אפשר להריץ על שרת ה-CI: גרירה מסייר הקבצים, החסן USB אמיתי ואנטי-וירוס.
כל השאר נבדק אוטומטית (`docs/TESTING.md`). יש למלא את טבלת הראיות לכל סעיף ולצרף אותה ל-PR או
לשחרור. סעיף שלא נבדק נשאר **Pending**; סעיף שנכשל הוא **Fail** עם תיאור, גם אם השאר עבר.

## לפני שמתחילים

- מחשב Windows 10 22H2 או Windows 11 (x64), משתמש רגיל (לא מנהל), Microsoft Defender פעיל (ברירת המחדל).
- המתקין של ה-commit הנבדק (`Morph-Setup-<גרסה>.exe`), מותקן בהתקנה רגילה.
- תיקייה בשולחן העבודה בשם עברי, למשל `בדיקות מורף`, ובה: `תמונה.png`, `מסמך.docx`, `סרטון קצר.mp4`,
  `ספר.epub`, `ארכיון.zip` (אפשר לקחת מ-`test/corpus` ולשנות שם).
- לפני כל סעיף: לרשום את ה-SHA-256 של קובצי המקור (`Get-FileHash <קובץ>` ב-PowerShell). אחרי הסעיף:
  לחשב שוב. **המקור אסור שישתנה בשום סעיף.**

## 1. גרירה מסייר הקבצים (Explorer)

| # | פעולה | תוצאה צפויה |
| --- | --- | --- |
| 1.1 | לגרור קובץ אחד (`תמונה.png`) מהסייר לאזור הגרירה | שורה אחת עם השם העברי, סוג "תמונה", יעדים מוצעים |
| 1.2 | לגרור חמישה קבצים בבת אחת | חמש שורות, כל אחת עם הסוג הנכון, בלי כפילויות |
| 1.3 | לגרור את אותו קובץ פעמיים | הוא לא מתווסף פעם שנייה |
| 1.4 | לגרור תיקייה | הודעה שתיקיות לא נתמכות; לא נוספת שורה |
| 1.5 | לגרור קובץ אל מחוץ לאזור הגרירה (על הכותרת) | החלון לא מנווט לשום מקום ונשאר באפליקציה |
| 1.6 | לגרור קובץ מתוך ZIP שנפתח בסייר (בלי לחלץ) | הקובץ מתווסף או מוצגת הודעה ברורה; אין קריסה |
| 1.7 | להמיר את כל השורות | כל השורות מסתיימות ב"הושלם"; הפלט ליד המקור בשם עברי תקין |

## 2. החסן USB אמיתי (FAT32 ו-exFAT)

| # | פעולה | תוצאה צפויה |
| --- | --- | --- |
| 2.1 | להעתיק את התיקייה להחסן FAT32 ולהמיר משם, פלט "ליד המקור" | הפלט נכתב על ההחסן; אין קובץ `.~morph-*` שנשאר |
| 2.2 | להמיר שוב אותו קובץ לאותו יעד | נוצר `שם (1).סיומת`; הקובץ הקודם לא נדרס |
| 2.3 | אותו דבר על החסן exFAT | כמו 2.1–2.2 |
| 2.4 | להתחיל המרת וידאו ארוכה ולשלוף את ההחסן באמצע | השורה מסתיימת ב"נכשל" עם הודעה; Morph לא נתקע ולא קורס |
| 2.5 | להחזיר את ההחסן ולפתוח מחדש את Morph | אין קבצי `.~morph-*` או קבצים ריקים חלקיים על ההחסן; המקור שלם (SHA-256 זהה) |
| 2.6 | להמיר מהחסן לתיקיית פלט קבועה בדיסק C (הגדרות → תיקייה) | הפלט בתיקייה שנבחרה; ההחסן לא השתנה |

הערת אבטחה: למערכות קבצים FAT32/exFAT אין הרשאות. הכליאה של מנועי ההמרה (AppContainer) לא
יכולה למנוע ממנוע לגשת להחסן כזה; זה מתועד כמגבלה ב-`docs/ARCHITECTURE.md` (D2).

## 3. אנטי-וירוס (Microsoft Defender)

| # | פעולה | תוצאה צפויה |
| --- | --- | --- |
| 3.1 | להתקין את Morph ולהריץ המרה אחת מכל משפחה (תמונה, וידאו, מסמך, ספר, ארכיון, PDF) | הכול מצליח; ב-Windows Security → Protection history אין הסגר (quarantine) של קבצי Morph או המנועים |
| 3.2 | להמיר עשרה קבצים ברצף לאותה תיקייה | אין הודעות "הקובץ נעול"/EBUSY; כל הפלטים קיימים |
| 3.3 | ליצור ZIP שמכיל את קובץ הבדיקה התקני EICAR (מחרוזת בדיקה לא מזיקה של ארגון EICAR) ולהמיר אותו ל-7z | Defender חוסם את הקובץ; ב-Morph השורה נכשלת עם הודעה, אין פלט חלקי ואין קבצים זמניים שנשארים |
| 3.4 | בזמן המרת מסמך ארוכה (LibreOffice) לסגור את Morph מה-X | Morph נסגר; ב-Task Manager אין `soffice.bin` שנשאר |
